---
name: react-frontend
description: Build accessible React and TypeScript marketplace screens.
---

- Use shared API helpers, same-origin credentials, and refresh the CSRF token after session changes.
- Render server state with clear loading, empty, validation, and error feedback.
- Keep customer, worker, and admin actions connected to real API behavior; do not invent availability, prices, or reviews.
- Use responsive semantic HTML, keyboard operation, labels, and adequate contrast.
- Run `npm run check --prefix src/frontend`, `npm test --prefix src/frontend`, and `npm run build --prefix src/frontend`.
